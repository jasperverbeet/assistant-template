# Research

Reports from research that agents did for the owner. Each report is one file:
`research/<area>/<YYYY-MM-DD>-<topic>.md`. Choose one area per project or
topic, for example `assistant`. The private reports are not in this copy.

- Write a report here when the research gives knowledge that stays useful,
  such as a measurement, an analysis, or a design decision.
- Daily job output stays in `inbox/reports/`. It is not research.
- Do not put names of customers, amounts of customers, or document contents in
  a report. Use IDs and aggregates.
- Add one line to the index below for each new report.
