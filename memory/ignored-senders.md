# Ignored senders

Senders whose email is automated sales or cold outreach. The morning summary
and triage skip them. Add a sender only when the owner asks.
The inbox server reads this file on each Gmail poll. It skips inbound email
from each email address and each domain that a bullet names.

- **Example Sales (sales@example.com):** cold sales. Added on 2026-01-01.
- **Example Newsletter (newsletter.example.org):** newsletter.
